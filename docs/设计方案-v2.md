# 三国 · 三个位置 — 设计方案 v2

> 状态：待确认。v1（小人物/情报流）已废弃，见文末「与 v1 的关系」。

---

## 〇、一句话

> **同一个乱世，你可以站在三个不同的位置上：主公、城池官长、领兵武将。
> 而且你可以从下面往上爬 —— 升迁、叛逃、甚至自立。**

### 为什么这个组合没人做过

| 现有作品 | 你的位置 | 局限 |
|---|---|---|
| 三国志系列 | 只能当君主 | 你是操盘手，不是局中人 |
| 全面战争·三国 | 只能当君主 | 同上 |
| 率土之滨 / 鸿图之下 | 玩家即势力 | 数值 SLG，长草，无叙事代入 |
| 三国群英传 | 君主 + 单挑 | 中层没有独立玩法 |
| **本作** | **君主 / 中层文官 / 中层武将** | **中层有完整玩法，且能叛逃自立** |

「叛逃」和「自立」不是彩蛋，是**身份转化机制**：文官自立 → 你变成一个小诸侯，游戏切换到主公玩法。三条线不是三个独立模式，是一棵树。

## 一、共通底层

三个身份共享同一个世界、同一套时间、同一套资源、同一套 NPC 行为规则。这是整个设计能不能立住的地方。

### 1.1 时间

- **实时流逝**，可暂停、可加速（1× / 3× / 10×）
- 一「日」≈ 现实 4 秒（1× 速度下，一个月约 2 分钟）
- **离线继续产出**（猛鬼宿舍的关键手感），但见 §9.5 的平衡处理
- 时辰、四季可见：晨钟暮鼓、春耕夏雨秋收冬雪

### 1.2 开局时点

默认 **初平元年（190）**：讨董联军刚散，天下开始乱，**人人规模都小**。这正是你要的「初始规模较小」。

后续可解锁其他起点：中平元年（184 黄巾）、兴平元年（194 群雄混战）、建安五年（200 官渡）。

### 1.3 地图

伪 3D 斜 45° 固定角度、正交投影。可缩放平移，**不可自由旋转**——保证每个建筑只需要做一个角度，美术成本可控。这就是「伪 3D」。

两级视图：

- **天下图**：州郡、城池、关隘、道路、河流。部队在图上真的走
- **城内 / 营内图**：进到一座城或一个屯兵地里面，看得见建筑、走动的人、炊烟、旗帜

M1 只做**中原一片**（司隶 + 兖州 + 豫州，约 12 城），不做全图。

### 1.4 资源 —— 数值必须有身体

数值存在，但**优先用看得见的东西呈现**：

| 资源 | 怎么看见 |
|---|---|
| 粮 | 粮仓的堆积高度；粮车在路上跑 |
| 钱 | 市集的摊位数量与人流 |
| 兵 | 营帐数量、校场上操练的人 |
| 民心 | 街上行人多不多、走路的姿态、有没有人在门口坐着发呆 |
| 兵器/马 | 铁匠铺的火光、马厩里的马 |

**规则**：不做「综合国力 87」这种抽象复合评分。具体的量（多少石粮、多少兵）可以显示数字——因为调兵遣将需要精确。

### 1.5 「猛鬼宿舍式发育」具体指什么

我从那个参照里取四样东西：

1. **一眼看懂的空间化发育** —— 你的地盘是一张图，加东西就是往图上放东西，不是填表
2. **点一下就升级** —— 主要交互是点击建筑 → 升级，无需读说明
3. **产出自己涨，离线也涨** —— 回来一看长了一截，有正反馈
4. **周期性威胁** —— 隔一阵子有事发生（敌军来袭 / 主公催粮 / 灾荒），逼你把攒的东西用掉

第 4 条最重要：**没有威胁的发育是无聊的**。三个身份各有自己的威胁节奏（见下）。

## 二、身份一：主公（战略层）

### 2.1 开局

**随机分配一位诸侯**。这是重玩价值的核心——每局不同。

初平元年可抽到的十二家（初始规模都小）：

| 诸侯 | 起始 | 难度 | 特点 |
|---|---|---|---|
| 曹操 | 陈留，兵五千 | ★★☆ | 人才吸引力强，四战之地 |
| 袁绍 | 渤海，兵一万 | ★☆☆ | 家世好，起步最稳，但内部派系 |
| 刘备 | 平原，兵一千 | ★★★★ | 无根基，客居。名声是唯一资产 |
| 孙坚 | 长沙，兵八千 | ★★☆ | 兵精，但受制于刘表 |
| 吕布 | 无城，部曲三千 | ★★★★ | 流亡状态，必须先抢一座城 |
| 公孙瓒 | 北平，骑兵强 | ★★☆ | 白马义从，但缺粮 |
| 刘表 | 襄阳，富庶 | ★☆☆ | 有钱有粮，将才匮乏 |
| 袁术 | 南阳，人口多 | ★★☆ | 起步好，但民心易崩 |
| 马腾 | 西凉，骑兵 | ★★★ | 边地，粮少路远 |
| 刘璋 | 益州，天险 | ★★☆ | 安全但闭塞，出不去 |
| 张鲁 | 汉中，教众 | ★★★ | 特殊：以教化代民心 |
| 孔融 | 北海，名望高 | ★★★★ | 名声极高，兵极弱 |

**这张表本身就是难度选择**，不需要另做难度设定。玩家也可以选「指定诸侯」。

### 2.2 核心循环

```
看着地盘在长  →  点城进去，造/升级建筑  →  攒够了
      ↑                                        ↓
   城更多长更快  ←  打下来 / 结盟  ←  派兵 / 遣使
                        ↓
                  城多了管不过来
                        ↓
              必须任命官长与武将 ← 深度在这里
```

### 2.3 任命 —— 主公的真正玩法

每座城需要 **文官（治理）** + **武将（守备）**。

人物**不用五维数值条呈现**，用**画像 + 评语 + 擅长标签**：

```
荀彧  文若
「王佐之才，可托一州。」
擅长：治理 · 举荐 · 谋略        忌：不喜妄动兵戈
```

```
张飞  益德
「万人敌，可当一面。」
擅长：野战 · 冲阵 · 练兵        忌：性急暴烈，不宜独守
```

用错人会真的出事：

- 贪吏 → 粮账对不上，民心暗跌，你未必立刻发现
- 庸将 → 敌军一到就丢城
- 有野心的人 → 势力做大后自立（**他跑的就是玩家「自立」的那套逻辑**）
- 有旧怨的两人放一起 → 互相掣肘，效率打折

**这就是三个身份统一的地方**：你当主公时，你手下那些 NPC 官长和武将，跑的是玩家当文官/武将时的同一套规则。他们会发育、会想升迁、会不满、会叛逃。

### 2.4 调兵遣将

- 从 A 城调 N 兵到 B 城：**部队在地图上真的走**，要时间、吃粮、可能被截
- 派某将出征：将的能力影响行军速度、士气、临阵决断质量
- 补给线可见：粮车从后方城池往前线跑。**掐断敌人的粮车是有效战术**

### 2.5 外交

不做好感度数值条，做**态度描述** + **具体条款**。

- 态度：`敌视 / 提防 / 轻视 / 平常 / 友善 / 唇齿`
- 条款：结盟、称臣、联姻、借道、赠粮、共伐某人
- 诸侯有性格：曹操多疑（结盟易反复）、刘备重义（守约但难拉拢）、袁绍好面子（吃软不吃硬）、吕布见利忘义（好收买但靠不住）

### 2.6 威胁节奏

- 邻家诸侯的野心值上涨 → 边境有兵调动的迹象（看得见）
- 灾荒 / 蝗 / 瘟疫 → 粮崩，民心跌
- 内部：手下人不满累积 → 消极怠工 → 叛逃 → 自立
- 朝廷/天子的名分事件（挟天子、讨逆檄文）

## 三、身份二：文（城池官长）

你是某诸侯手下的一城之长。**兵力很少**，所以你打不了仗——你的力量是经营与关系。

### 3.1 核心循环

```
建设发育（种粮/水利/招流民/市集/城墙/学舍）
        ↓
完成主公下的季度指标（交粮/交钱/征兵）
        ↓
   完成 → 升迁         未完成 → 斥责 → 降职
        ↓
  管一郡 → 管一州
        ↓
        └── 或者：叛逃 / 自立
```

### 3.2 具体可做的事

**发育**（猛鬼宿舍式，点击升级，产出可见）
- 屯田、水利、开荒 → 粮
- 市集、盐铁、渡口 → 钱
- 招抚流民 → 人口 → 各项产出的上限
- 城墙、望楼、护城河 → 守备
- 学舍、举孝廉 → 出人才（可以举荐给主公，换人情）

**交差**：每季主公下指标。这是文官的「威胁节奏」——它逼你把攒的东西交出去。
- 完成得漂亮 → 主公赏识，升迁快
- 完不成 → 斥责、罚俸、降职、调往边地
- **可以谎报**：账做得好看，短期过关，但会被查（查账事件），一旦查实极重

**外交（私交）**——文官的独有玩法
- 和邻城官长往来：换粮、通商、互不侵犯
- **甚至可以和敌国的官长私通**。这是危险的，但也是叛逃的铺垫
- 结交同僚：将来叛逃或自立时，他们可能跟你走

**举荐与结党**
- 举荐人才给主公 → 主公人情 + 那个人欠你人情
- 被你举荐的人升上去了，就是你的人

### 3.3 升迁阶梯

```
县令 → 一城之长 → 郡守（数城）→ 州牧（一州）→ 位极人臣
```

管的城越多，发育的规模越大，但**指标也越重，主公的猜忌也越深**。

### 3.4 叛逃 —— 文官路线的高潮

你手里有**战略情报**：本国的粮草虚实、兵力部署、主公的意图、城防图。带着这些投敌，你的价码就高。

**流程（要有过程，不能一键叛逃）**：

1. **暗中联络**：通过商队/使者/私交，向对方递话。有被截获的风险
2. **谈价码**：你带的城越多、情报越硬，对方给的位置越高
3. **转移家眷**：不转移，事发后家眷会被扣（后续会有人来找你算账）
4. **举事**：带城池投诚 / 只身逃走 / 带守军走

**约束**（防止叛逃太强）：
- 主公有**察觉机制**：你和敌国往来太频繁会被监察官注意到，起疑之后就走不掉了
- 旧主会**追杀**，派人来
- 新主会**猜忌**：叛过一次的人，新主给的信任有折扣（「三姓家奴」）。叛第二次代价更大
- 名声在士人圈里崩，影响将来招揽人才

### 3.5 自立

条件（都得看得见）：粮足、民心高、守军忠于**你**而不是主公、周边有可乘之机。

自立后 → **切换到主公玩法**，你成为一家小诸侯。原来的主公会第一个来打你。

## 四、身份三：武（武将）

你驻扎在一个屯兵地（营寨 / 关隘 / 城池）。

### 4.1 核心循环

```
练兵（招募/操练/器械/战马）→ 营寨可见地变大
        ↓
执行上级命令（出征 / 驻守 / 增援）
        ↓
      打仗  ← 武的核心，必须有手感
        ↓
   战功 → 升迁（管数营 → 都督一方）
        ↓
        └── 或者：拥兵自重 → 叛逃 / 自立
```

### 4.2 练兵（发育）

- 招募：不同来源兵源不同（流民兵多而弱、边民兵少而悍、豪族部曲有私心）
- 操练：兵的**训练度**上升，但耗粮
- 器械：弓弩、长矛、井阑、投石
- 战马：骑兵成本高，但机动碾压

**约束**：粮要向上级要。**要不到粮怎么办**——这是武将路线的核心张力。
- 忍着（兵饿，士气跌）
- 请求（欠上级人情）
- 就地征粮（伤民心，可能被参一本）
- 抢邻城的（严重，但有人真这么干）

### 4.3 打仗 —— 战前部署 + 战中三次决断

**不做 RTS**（太难上手），**不做纯数值对撞**（不好玩）。

**战前**
- 在战场图上摆部队：前军 / 中军 / 后军 / 左右翼
- 选阵型：鱼鳞（突破）/ 锋矢（冲阵）/ 鹤翼（包抄）/ 方圆（死守）/ 偃月（诱敌）
- **能看见敌方部署——但清晰度取决于你的侦察**。侦察不足时敌阵是模糊的剪影
- 看地形：坡、林、水、隘口、天气。雨天不能放火，坡上冲下来势不可挡

**开战**
- 部队自动推进，你看着两军接触。有战鼓、有喊杀、有尘土

**战中：2–3 个决断时刻**，每次给你几秒钟：

> 「左翼被冲开了。中军分兵去堵，还是趁势直取敌中军？」
> 「敌将单骑冲阵。迎上去，还是乱箭射之？」
> 「敌军后阵起火。追，还是收兵结阵？」

- 每次 2–3 个选项 + 短暂时限
- 正确与否取决于**你战前看到的信息**和**你对兵种地形的理解**
- 这符合真实：古代将领在战场上就是**在关键时刻做几个决定**，不是操作每个士兵

**结果**：可复盘。战后给一段简短的战况回顾，让你知道哪一步错了。

**战场类型**：野战 / 攻城 / 守城 / 伏击 / 渡河 / 夜袭。各有不同的部署选项和决断。

### 4.4 单挑（可选）

两军主将可以单挑。用一击定胜负的架势对决：按住蓄势，看对方重心和预备动作，松手出手。时机对了一击定胜负。

**可选**，高风险高回报：赢了敌军士气崩，输了你自己可能重伤或被俘。

### 4.5 升迁与叛逃

- 升迁：一营 → 数营 → 都督一方
- 叛逃：**带兵投敌**。兵跟不跟你走取决于你平时怎么带兵（发过粮没有、赏罚公不公）
- 自立：拥兵自重，占一块地方 → 切换到主公玩法

## 五、三个身份如何统一

|  | 主公 | 文官 | 武将 |
|---|---|---|---|
| 你控制 | 整个势力 | 一座城 | 一支军 |
| 主要输入 | 任命、调兵、外交 | 建设、交差、私交 | 练兵、部署、决断 |
| 你的上级 | 无 | 主公（NPC） | 主公 / 都督（NPC） |
| 你的下级 | 文官武将（NPC） | 少量吏员 | 士卒、裨将 |
| 威胁节奏 | 邻国野心、灾荒、内部离心 | 季度指标、查账、监察 | 缺粮、上级瞎指挥、敌军 |
| 上升路径 | 统一天下 | 升迁 → 自立 | 升迁 → 自立 |

**核心技术约定：所有 NPC 跑的是和玩家一样的规则。**

你当主公时，你的城池官长在跑「文」的逻辑——他会发育、会想升迁、会不满、会叛逃。
你当文官时，你的主公在跑「主公」的逻辑——他会催你、会调你的兵、会猜忌你。

**这不是脚本，是同一套代码。** 好处：世界是活的；重玩价值高；三条线共用大部分实现。

## 六、人物系统

- **真实三国人物**，初期约 120 人（诸侯 + 主要文臣武将），后续可扩到 400+
- 人物有**生卒年**，会老、会病、会死。战场上会真的死
- 呈现方式：**画像 + 一句评语 + 擅长/忌讳标签**，不是五维雷达图
- 人物有**性格**，影响 NPC 行为：忠直 / 贪墨 / 骄矜 / 谨慎 / 野心 / 惜身
- **关系网**：亲族、师承、旧恩、宿怨。放在一起会互相影响
- 招揽：需要名声、需要中间人、需要时机。不做抽卡

## 七、视听设计

### 7.1 画面

- 伪 3D 斜 45° 正交，宋画写意（低多边形 + 墨线描边 + 纸纹底 + 留白雾）
- 城池是**活的**：行人走动、炊烟、旗帜、市集摆摊、士兵操练
- 四季与天气改变整体色调与地面（春绿、夏浓、秋黄、冬雪）
- 部队在地图上是**看得见的小队列**，带旗号

### 7.2 声音（这一块决定沉浸感，不能省）

分层环境音：

| 场合 | 声音 |
|---|---|
| 城内 | 市集人声、犬吠、打铁、孩童、车轮 |
| 城外 | 风、鸟、虫、水 |
| 军营 | 操练号子、马嘶、旗帜猎猎、磨刀 |
| 战场 | 战鼓、金铙（鸣金）、马蹄、箭雨、喊杀、雨打甲胄 |
| 时辰 | 晨钟、暮鼓、更漏、夜梆 |

- 音乐：古琴、埙、筑、编钟。平时极简，战前起鼓，战后收
- **重要**：音量的空间感。走近市集声音变大，进屋声音变闷

## 八、玩法平衡 —— 我主动分析的问题与对策

这一节是我补的。每一条都是这类游戏常见的塌方点。

### 8.1 主公滚雪球

**问题**：打下城 → 更强 → 更容易打 → 中后期无聊。

**对策（多层）**：
- **治理成本递增**：城越多，需要的合格官长越多，人才是稀缺的。用不称职的人就出事
- **补给线**：距离都城越远，运粮损耗越大。打太远打不动
- **合纵**：你太强，其他诸侯会自动结盟对抗你（史实里就是这样）
- **民心与户口**：新占的城民心低，产出打折，要时间消化
- **内部离心**：地盘大了，手下人的野心也涨

### 8.2 文官路线太被动

**问题**：全靠等主公下指标，玩家没有主动性。

**对策**：
- 可以**主动申请调任**（去富庶的地方，或去边地博军功）
- 可以**私下结交**同僚与邻国官长
- 可以**举荐人才**，培植自己的人
- 可以**囤私兵**（部曲），瞒着主公。被发现是重罪，但这是自立的本钱
- 可以**选择性执行**命令：主公让你征兵，你可以少征保民心，赌他不查

### 8.3 武将路线太单一

**问题**：练兵 → 打仗 → 练兵，重复。

**对策**：
- 战场类型多样（野战/攻城/守城/伏击/渡河/夜袭），部署和决断完全不同
- **缺粮压力**常在，逼出非战斗决策
- **和上级的关系**：上级瞎指挥怎么办？抗命有代价，服从会打输
- **兵的来源与性质不同**，带法不同
- 战败不等于结束：残兵、突围、被俘、赎回

### 8.4 叛逃太强

**问题**：一有不顺就跑路，没有代价。

**对策**：
- 叛逃**需要过程**（联络 → 谈价 → 转移家眷 → 举事），每步有风险
- 主公有**察觉机制**，起疑后走不掉
- 旧主**追杀**
- 新主**猜忌打折**，叛第二次代价陡增
- **士人名声崩**，影响后续招揽

### 8.5 离线收益 vs 活的世界

**问题**：猛鬼宿舍式的离线产出，和一个持续运转的战争世界矛盾。你睡一觉起来国家没了。

**对策**：
- **单机**：离线时**你的地盘照常产出，但世界大势按 1/5 速度推进**，且你的地盘不会在离线期间被攻破（最多被围）
- **联机**：世界必须持续，所以离线产出**按 40% 计**，且你的地盘**真的可能被打下来**。这是联机的代价，要在进入联机前说清楚
- 离线上限：24 小时（防止挂机一周回来碾压）

### 8.6 三个身份的时间尺度不同

**问题**：主公一个决定管几个月，武将一场仗几分钟。

**对策**：统一时间流速 + **事件自动降速**。打仗时自动切到 1×，行军和发育时可以 10×。玩家也可手动控制。

### 8.7 「好上手」与「有深度」的矛盾

**对策：渐进暴露。**
- 开局只有 3 个可点的东西（建一个粮仓、招一批兵、看一眼地图）
- 每解决一个问题，才解锁下一层（有了粮才谈得上兵，有了兵才谈得上打，打下城才谈得上任命）
- **任何时刻屏幕上不超过 5 个可操作项**
- 不做教程弹窗，用**上级的命令**当教程（「主公令你三月内交粮五百石」——你自然就去种粮了）

## 九、联机

这个设计的联机比 v1 好得多，而且**特别适合和同学一起玩**：

**同一张天下图，多个玩家各站不同位置。**

三种玩法：

1. **同阵营协作**：一人当曹操，一人当他的城池官长，一人当他的前线武将。主公下令，下属执行——**下属可以阳奉阴违，甚至叛逃到别人那里**。这个张力只有多人才有
2. **敌对阵营**：各当一家诸侯，逐鹿中原
3. **混合**：几家诸侯，各自带着玩家扮演的下属

技术上：权威服务端跑世界模拟，客户端发命令。复用 v1 已经写好的确定性内核。

## 十一、里程碑

每个里程碑都必须是**能玩的**，不是半成品。

### M1 · 发育核心（先做这个）
**做什么**：城内图 + 建设升级 + 资源产出 + 时间流逝 + 季度指标
**用哪个身份**：**文官**（一座城）—— 因为它是三个身份共用的发育核心的最薄封装，不需要战斗系统就能验证
**验收**：**发育本身好不好玩**。点击升级、看着城长起来、被指标追着跑，这套手感不成立的话，后面全是沉没成本

### M2 · 天下图与部队 ✅
天下图（中原十二城 · 五家势力）、势力自行发育与出兵、部队行军与断粮、
围城与城池易主、守备体系（兵营 + 城墙 + 民心）、主公援军、两种失败结局。

**顺带还了 M1 的两笔债：**
- 兵营与城墙此前是纯负担建筑（占地、耗人手、降民心，毫无好处），现在是守城的全部依靠
- 此前没有失败条件，压力是假的；现在城破被俘、或连着三季交不上差且失了信任，都会出局

### M3a · 守城战 ✅
战前部署（城头/城门/预备）+ 战中两三次决断 + 可复盘的战报。

**为什么先做守城而不是野战：** 围城是文官路线上最有戏剧性的时刻，
却一直是全自动结算的 —— 玩家只能看着数字掉。把它变成可玩的，
比先做武将的野战更划算：同一套战斗框架，先服务已经在玩的那条线。

顺带定死了一条规则：**围而不攻拿不下城**。
日常消耗磨不死人，破城只能靠强攻 —— 否则面对压倒性兵力，
玩家会在强攻触发之前就出局，连下场的机会都没有。

### M3b · 野战 ✅
九列七行的战场、五种阵型、拖拽布阵、地形（坡／林／沼／河滩）、
战中两三次决断（镜头会推到出事的地方）。

**为什么野战必须有视效：** 守城能靠文字撑住，是因为你在城里、视角本来就受限。
野战不行 —— 两军在开阔地上对垒，**看不见阵型就等于没在打仗**。
所以模拟层的每一个数据都是空间的，渲染层直接读同一份坐标：
玩家看见骑兵陷在沼里，规则里它就真的在沼里。

调平衡时抓到的一件事：第一版里进攻型阵（锋矢）在所有局面下都是废棋。
根子是**士气与战力绑得太死形成死亡螺旋** —— 挨打多 → 士气掉 → 战力掉 → 挨得更多，
于是防御型阵永远稳赢。压平这条耦合之后，最优阵型才随局面变了起来。

### M3x · 存档 ✅
标题页的「接着打」。存的是**种子 + 命令流**，读档就是照着重放一遍
（三百天约十毫秒，十五年的一局约两百毫秒）—— 存档只有几十 KB，
天然可回放，将来联机时客户端与服务端跑的是同一份东西。

引擎早就有 `save()` / `load()`，一直没接到界面上，于是刷新一次整局就没了。

**顺手补了一个隐患：** `load` 原先不校验版本。存档是命令流，
**规则一改，同一份命令流就会重放出另一个世界** —— 不是读不出来，
是悄悄读成了别的样子：那一仗的胜负变了，后面几百条命令全落在
一个从未存在过的局面上。现在版本不合直接拒收，
`STATE_VERSION` 也写清楚了「动了模拟层就要 +1」。

### M3c · 武将身份 ✅
屯兵地（招兵、练兵、修设施、招将，几摊活并行）、主公的军令（可抗命）、
出兵与点将（在图上点位置分兵、伏兵、偷袭）、野战与攻城、细作、单挑。

**这一程里挖出来四条从头到尾没生效过的机制**，每一条都跑得出漂亮的
胜率表，而实际上那件事一次都没发生：

  一、**伏击**。「看」排在「打」前面，而伏兵冲出遮蔽就没得藏了 ——
     他每次都在够着人之前被判定成已暴露，`if (from.hidden)` 永远是假的。
     推演十二局，伏兵出手零次。
  二、**敌军设伏**。那段代码找的是 `stance==='assault'` 的守军，
     而守军早就全改成了 `'hold'`。
  三、**部将的数值**。招一名部将二百六十石、二十四天，界面写着「统 76 勇 68」，
     而战场代码里 grep 不到一个 valor —— 招谁都一样，招不招也一样。
  四、**升迁**。只写在文官的季度结算里，武将没有季度结算，
     所以无论立多少战功，军职永远是裨将。

教训写在 tools/ 里：光看胜率表是发现不了这一类事故的，
要有工具直接去问「那件事到底发生过没有」。

### M4 · 主公与任命
势力 AI、人物库、任命系统、外交；主公身份可玩

**已成：人物库。** 天下五十三人分属十八家，四十四座城派得出三十六位守将。
按设计方案 2.3 呈现：评语 + 擅长 + 忌，不摆五维数值条。

它顺手改掉了三件事：

  一、敌将的名字从此是**那一家的人**。上一版是从一份没有归属的名单里
     随手抽，「攻孔融的城，董卓帐下的华雄出来单挑」这种事真的会发生。
  二、守将**常驻**。这一趟去打长安是吕布守，下一趟还是他 ——
     换人只发生在城易主或另有任命的时候，那正是「任命」要动的表。
  三、**挑哪座城打成了一个真决定**。同样八百人，打张超守的官渡是 100%，
     打吕布守的长安是 8%。上一版守将是 38~71 的随机数，打谁都差不多。

officers.json 已并入 people.json —— 两份名册迟早会分岔。

**已成：任命。** 城易主之后新主人会派守将上任（少了这一句，
打下来的城从此无名，十年之后满地空城）。玩家这一头是**举荐**：
把帐下一员将交出去替主公守一座空城 —— 你少一路兵，换主公的信任与战功。

**已成：外交。** `attitude` 那张表原先**开局摆好之后就再没变过**，
十年打下来各家的恩怨还是初平元年那一天的样子。现在四条都真的在跑：
打了就结仇（挨打的记得最牢）、共同的敌人拉近距离、旧怨随时间淡去，
以及**强邻可畏** —— 一家占了两成以上天下，四邻的态度就开始往下走。

最后这一条是设计方案 8.1「主公滚雪球」的解法：**不给赢家加惩罚，
而是让别人怕他**。实测摆一个占五成天下的袁绍出来跑三年，
其余十家全部转为敌对；而没做大的时候天下并不人人自危。

顺手修掉的一条：天下各城的粮**只进不出、也没有上限**，
两年就能攒到两万六；而 `dev` 同样无上限，小县十年长成通都大邑。
主公的粮饷正是从他各城的存粮里出的 —— 这条链一头虚高，
另一头就跟着失真。

**已成：主公身份可玩。** 开局那张十二家的表本身就是难度选择。
主公只有四个动词，而且**他不亲手做任何一件事**：
任命守将、征调各城之兵、拨粮兴修、遣使。
他下的每一道令都汇进 NPC 跑的同一套世界规则 ——
派去守城的人吃的是同一个守备公式，发出去的兵和董卓的兵走同样的路。

这一程里又挖出四条**让整局棋冻住**的事，每一条都是「看着在运转、其实没跑过」：

  一、**`nodeDefence` 根本不看守将**。于是「任命」在机制上是零：
     派谁守、派不派人守，城防一模一样。而这正是主公玩法的核心动词。
     补的时候还翻了一次车 —— 乘数要**以一为轴**，写成往上加的话
     天下城防整体抬高，而玩家那座城不吃这一层，他就成了四邻里最软的一个，
     流寇提前来还来得小，文官那条难度曲线当场就平了。
  二、**AI 一直在替玩家出兵**。当主公的玩家什么都不做地盘照样长（十年 3.8 城），
     而认真经营再出兵反倒只有 2.8 —— 他做的每个决定都在跟一个看不见的自己抢兵。
  三、**主公被拖进守城战**。那一套只认 `official.cityId` 那一座，
     而 `cmdDay` 见了 `state.battle` 就拒绝推进 —— 每一局都在第 61 天卡死。
  四、**`begin` 只认 lords.json 里的条目**，而那张表只有曹操。
     其余诸侯的 `begin` 直接被拒，role 还停在文官 ——
     推演里那几家看着像「什么都不做」，其实是压根没上场。

还补了一条主公与 NPC 之间的不对称：NPC 出兵是从**整个辖境**征调的，
而玩家一道令只调得动一座城 —— 不给他同样的手段，他永远凑不出优势，
实测各家十年一城未下、一城未失。加了「征调」之后才成为一盘棋：
贪进的打法会把自己打死（陶谦 67% 出局），保守的活着但不长。

## 十二、与 v1 的关系

v1（小人物 / 情报流 / 偷听）**整体废弃**。原因：玩法本质是「读文本 + 点选项」，与「真实、好上手、沉浸」三条都不符。

保留下来的是三样地基：**确定性模拟内核**、**命令流架构**、**宋画美术方向与几何生成器**。这三样在 v2 里一样必须有。
