# 主公方案 · v2「盖棺论定」

> v1 讲的是**手感**（案头、心气、派系）—— 让主公每一步都有阻力。
> 这一份讲的是更前面的两件事：**这盘棋要往哪儿去**，以及**主公到底在干什么**。
>
> 因为 v1 就算全做完，主公仍然是一盘**只能输、不能赢**的棋。

---

## 一、真正的洞在哪

### 1.1 代码里根本没有胜利条件

[`world_types.ts`](../src/sim/world_types.ts) 里的 `EndingKind` 只有三种，全是输法：

```
'dismissed'  交不上差被撤职   —— 官长的
'captured'   城破被俘         —— 官长的
'scattered'  地盘丢光         —— 主公唯一的一条
```

`checkLordEnding()` 只干一件事：数你还剩几座城，剩 0 就出局。

**没有任何一行代码定义「赢」。**

所以主公这一局的形状是：开局 → 打 → 打 → 打 → 打腻了关掉。
不是玩法薄，是**这盘棋没有终点**。人在一件看不见头的事上，投入感是撑不住的。

### 1.2 主公在用官长的时间

主公屏上挂着 `［❙❙］［1×］［3×］［10×］`，日历一天天走。
但 [`handlers.ts:391`](../src/sim/handlers.ts) 那一段是空的 —— 他的一天什么也不发生。

于是玩家在做的事是：**开 10 倍速，看日历，等一件事发生。**
这就是「体验感偏弱」最直接的来源 —— 他不是在做决定，他是在等。

### 1.3 三条线里，只有主公碰不到已经做好的那两套战斗

M3a 守城战、M3b 野战 —— 阵型、决断、九列七行的战场、单挑，全做完了。
官长打得到，武将打得到，**主公一次也用不上**。
项目里做得最厚的东西，主公线一分钱没花上。

## 二、终局：不做「统一天下」，做「盖棺论定」

### 2.1 为什么不用「打下全图」当胜利

设计方案 §8.1 花了整整一节在压**滚雪球**：新破之城的离心、百日无人再碰、
强邻招人忌惮、开发度有上限……全是为了不让赢家越滚越快。

如果胜利条件是涂满地图，那这一整套防滚雪球的设计就从「让局面有来有回」
变成了「拖延你赢的障碍」。**同一套机制，含义正好反过来。**

而且史实里也不是这么回事：曹操到死也没统一，刘备没有，孙权没有。
汉末诸侯的胜负从来不是「谁占的地多」，是**「你死那天，这份基业还在不在，天下怎么说你」**。

### 2.2 核心新招：主公会死，而死了游戏不结束

**主公有寿数。**

孙坚中流矢，袁绍病死，刘表病死，曹操活到六十六。
汉末的诸侯多半不是被打败的，是**没时间了**。

- 寿数是暗的（史实寿数 ± 抖动），**永远不给数字**
- 只给征兆，而且是话不是数：一年前起，呈报里开始出现
  「主公春秋高，宜早定大计」；朝会减少；某个月你会读到「近来常觉倦」

于是整局的问题从「我要打到什么时候」变成了 **「我还剩多少年，够不够」**。
这一句是把「无限的沙盒」变成「一个有形状的故事」的全部秘诀。

### 2.3 赢要三根柱子，只有一根是打出来的

要走到最高的那个结局（**开国**），你得同时凑齐：

| 柱子 | 是什么 | 怎么来 |
|---|---|---|
| **土** | 几座**有分量的名都**（洛阳 / 许 / 邺 / 寿春这一档），不是数量 | 打、或受让、或人家归附 |
| **名** | 望到某个层次，或天子在手，或走完王爵这级台阶 | 赈灾、守约、迎奉、讨逆 —— 全不是打仗 |
| **人** | 帐下得有**够分量的一批人肯替你上劝进表** | 你一辈子怎么待人 |

三根里两根跟军事无关。**这是这个方案最想要的那句话：
主公赢在他怎么当人，不是赢在他兵多。**

### 2.4 题眼：赢不是你点的按钮，是你的人替你把话说出口

**劝进是一件呈报。**

土和名到位了，案头某一天会摞上这样一件：

```
　邺城　荀彧　　　　　　　　　　　　　　　　　　　　　九日前
　「今海内分崩，唯明公足以定之。群臣议上尊号，
　　彧不敢不以闻。」

　　　　　　　　　　　　　　　　　　［　受　］［　辞　］［　斥　］
```

- **受** → 走进最后一幕。天下所有势力对你 `attitude` 一起跌，但你名正言顺。
- **辞** → 望 +（三辞三让是真的加分），劝进表以后还会再来，而且分量更重。
  但**你在赌你还活着**。
- **斥** → 你这辈子不称帝了（曹操路线）。这条路通向「托孤」那个结局，
  而且帐下私账是「义」的人心气大涨。

**没有人上这道表，你就称不了。** 你可以有全天下的地，
但如果你这一路上把人得罪光了、没人肯替你说这句话 —— 你就走不到那个结局。

这条把 v1 的心气 / 派系 / 旧账全部接上了终局：
**你两年前驳掉的那件事，会在最后一幕跟你算账。**

### 2.5 另一条路：不等劝进，强行称帝

这是袁术。**这是一条真的、可选的、会死人的路。**

不看望、不看人，只要你占着一座名都就能点。点下去之后：

- 天下所有势力 `attitude` 一次性暴跌，且**互相之间的敌意反而缓和**
  （共同敌人拉近关系 —— 这条 [`diplomacy.ts`](../src/sim/diplomacy.ts) 里现成就有）
- 帐下私账是「义」的人当场求去或叛逃
- 但你从此可以用皇帝名义封赏：招人的权重大涨，劝降敌将的成功率大涨

**赢面小，但赢了是最快的一条。** 玩家会知道自己在赌什么。

### 2.6 四种结局 —— 不是胜负屏，是史书上的一段

结局不给「Victory / Defeat」，给**盖棺论定**：一段像史书的评语，
外加一张「你这一生」的时间轴（哪年得了哪座城、哪年谁离开了你、哪年天下开始称你什么）。

| 结局 | 条件 | 味道 |
|---|---|---|
| **开国** | 受劝进 / 强行称帝，且基业传到第三代不倒 | 最高。但要活着走到，还要死后立得住 |
| **托孤** | 你没称帝，但死时安排立住了：继承人接住了，二十年后国仍在 | 最「三国」的结局。刘备白帝城 |
| **身死业分** | 你死了，儿子们打起来，地盘被瓜分 | 袁绍。**是失败，但是体面的失败** —— 你确实做大过 |
| **无人肯为之死** | 地盘丢光（现在那条 `scattered`） | 最低 |

**失败不是「游戏结束」，是「史书上那一段写得不好看」。**
这一条比任何胜负判定都更能让人想再来一局。

### 2.7 托孤：全局最后、也最重的一道任命

你快死的时候，案头会摞上最后一件事。两个决定：

**一、立谁。**
- **立长** —— 稳，各派没话说，但他多半平庸
- **立贤** —— 能力好，但**另一派不服**（袁绍立幼、刘表废长，两家都是这么散的）

**二、谁辅政。**
这一条等于把权交给哪一派。选出来的人会**跑主公那一套逻辑**：

- 选对了 → 继承人稳过头几年
- 选了太强的 → **权臣**。你儿子变成傀儡，他甚至会取而代之
  —— 那正是 M5 里玩家自己能干的「自立」，只是这回轮到你被人干
- 两派各选一个 → 他们会斗，斗到一方倒下

**你活着能压住的两派，你儿子压不住。**
所以 v1 里你每一次偏袒，都是在给这一天埋雷。这是全套设计里最长的一条因果线 ——
**十年前的一件小事，在你死的那一刻结账。**

### 2.8 死了接着玩：第二代

基业还在，就接着玩你的继承人。但他**不是你**：

- 他有自己的能力和性子（从你的子嗣里生成，或用史上的人：曹丕、袁谭、刘琮）
- **他的望从零起** —— 望不继承，人望是自己攒的
- 他继承你的**仇**（`attitude`）和你的**派系烂账**
- 老臣看他的眼光跟看你不一样：跟过你的人心气基线一律 −，
  「主公在时不是这样的」

**三代不倒才算「开国」。** 这让一局的长度有了自然的分幕，
也让「你怎么对人」这件事有了一个必须结账的时刻。

## 三、体验：主公的时间不该按天走

### 3.1 把速度条换成「散朝」

主公没有日常，所以他不该有日历。改成**事件驱动**：

```
　　　　　　　　　　　［ 　散　朝　 ］
　　　　　　　　　（天下自己走，走到下一件要你拍板的事）
```

按一下，世界跑十天、跑三十天、跑到下一件呈报／战报／使者到门为止。
中途出大事（城被围、有人叛、天子东归）会**自动停住**，
就像守城战里「打仗时时间停住」那条一样。

主公看到的不再是日历，是**一件事接一件事**。
这一改几乎不动模拟层（还是那个 `cmdDay` 循环），
但它是「体验感偏弱」最便宜、最见效的一刀。

### 3.2 三个场景，取代现在的「一张图 + 一块面板」

| 场景 | 看什么 | 管什么 |
|---|---|---|
| **堂上** | 案头呈报（默认屏） | **事** |
| **图上** | 天下图，**带迷雾**：远处是旧消息、是传闻 | **地** |
| **帐前** | 人按派系站班，谁称病、谁跟谁不睦一眼看得见 | **人** |

三个场景对应三样资源，而不是像现在这样十二座城各一块小面板。

### 3.3 亲征 —— 主公唯一亲手做的一件事

**这是最划算的一条：零新战斗代码，直接把做好的两套战斗接进主公线。**

你可以亲自领兵出征。到了地方，切进现成的野战 / 攻城玩法
（阵型、决断、单挑，一切照旧）。

代价三条，一条比一条重：

1. **你不在都城。** 亲征这些日子案头没人批 —— 呈报照样堆，照样过期。
   回来的时候后方多半出了事。
2. **兵是从各城抽的。** 你走之后，边境是空的。
3. **主公亲征会死。** 一支流矢就够了（孙坚就是这么没的）。
   概率不高，但它是真的 —— 而且它会**直接触发托孤那一幕**，
   在你完全没准备好的时候。

亲征赢面比派人大得多。**所以这是全局张力最大的一个取舍：
你在赌你的命，和你的后方。**

## 四、一局有多长，长什么样

一局主公 ≈ **十五到二十五年游戏内时间 ≈ 现实三到五小时**。三幕：

| 幕 | 大致 | 案上主要是什么 | 你在想什么 |
|---|---|---|---|
| **一、起家** | 前 5 年 | 请粮、请战、举荐 | 活下去，攒人 |
| **二、争衡** | 中 10 年 | 告状、派系倾轧、来使、时局表态 | 平衡内部，挑一家吃掉 |
| **三、摊牌** | 后 5–10 年 | 劝进、求去、托孤 | **我还剩几年** |

第三幕的所有压力都来自同一件事：**时间不够了。**
这是整个方案里唯一一个不需要靠敌人制造的紧张感。

## 五、顺带把这棵树的顶补上

三条线现在各有各的输法，但**只有主公线该有「赢」**：

| 身份 | 终点 |
|---|---|
| 城池官长 | 升迁到一州之牧 → 继续往上；或**自立** → 切主公线 |
| 领兵武将 | 封侯拜将 → 继续往上；或**自立** → 切主公线 |
| 主公 | **开国** |

所有的路最后都通向同一件东西：**那一道劝进表。**
「从下往上爬」这句宣传语，到这里才第一次有了一个顶。

## 六、做的顺序（按「多便宜换多少体验」排）

**第一期 · 先给这盘棋一个头**
寿数（暗）+ 望 + 四种结局 + 劝进（这一期先只看土与望）+ **散朝**（事件驱动时间）。
> 便宜，而且改完当场就不一样了：终于有终点，终于不用看日历。

**第二期 · 亲征**
接现成的野战 / 攻城；主公不在时案头照堆；流矢判定。
> 几乎零新代码，主公线立刻有了「玩」的部分。

**第三期 · 案头与心气**（= v1 的 M4.5a）
呈报队列 + 心气 + 「不再上报」。劝进从这一期起**改成要人上表**。

**第四期 · 派系与托孤**
`clique` + 零和心气 + 立长 / 立贤 + 辅政 + 权臣 + **第二代接着玩**。

**第五期 · 时局与献策**（= v1 的 M4.5c/d）

每一期都要能单独玩完一局。

## 七、怎么验证这套东西真的活着

照 `dead-mechanic-audit` 那条教训，`tools/lord.ts` 跑一百局，打印**分布**：

```
一百局的结局分布
　开国            9
　托孤           23
　身死业分       31
　无人肯为之死   37

平均寿终           第 6820 日（第 18.7 年）
劝进表出现         64 局　　受 41 / 辞 15 / 斥 8
强行称帝            7 局　　其中活到最后 1
主公亲征          312 次　　阵殁 6
死于「没时间了」   28 局（土名人齐了两根，第三根没凑齐就死了）
第二代守住         19 局 / 32 局
```

要盯的不是哪一档高，是**四种结局都得有人拿到**。
任何一档接近 0，那条路就是假的 —— 尤其是「开国」：
如果一百局里 0 次开国，这游戏就是不能赢；如果 60 次，那它太好赢。

另外必须专门数一条：**「死于没时间了」**。
这个数应该是四种结局里最让人想再来一局的那个原因。
它要是 0，说明寿数根本没在给压力，那 §2.2 整节就白写了。

## 八、为什么这套不违反三条硬规矩

1. **不做数值面板** —— 寿数永远不给数字，只给「近来常觉倦」；
   望是天下人的一句评语；结局是一段史书，不是一个分数。
2. **资源是对象** —— 新增的两样资源，「人」在堂上站班，「时间」是你自己的白发。
   两样都看得见。
3. **楔子只改权重** —— 望、名分、时局改的全是现成公式上的乘数；
   连称帝这么大的事，改的也只是 `attitude`、招人权重、劝降成功率这三个旧旋钮。
   一条新规则也没有岔出去。
