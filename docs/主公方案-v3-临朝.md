# 主公方案 · v3「临朝」

> v1 把主公从「四个无条件按钮」改成了「案头 + 心气 + 终局」，机制是活的
> （`npm run court` 里四种结局都有人拿到，心气、劝进、兼并都真的在跑）。
>
> 但玩起来还是**一页纸加一堆选项点点点**。
>
> 这份东西要治的就是那句话。

---

## 一、诊断：机制活了，为什么还是不好玩

不是内容不够 —— 案上七种呈报、三根柱子、四种结局都在。缺的是**三样感觉**。

### 1.1 世界不可见

你批完一件事，屏幕上什么都没变。粮车确实在图上走 —— 但图在另一个标签页，
你不会去看，去看了也只是一张静图。

**「我拨动了什么」这件事，玩家一次也没看见过。**

### 1.2 人不可见

呈报是一张卡片。卡片上有一张小画像，但那张脸不会动、不会看你、不会因为你驳了他而变色。
心气是这条线的心脏，而它**唯一的出口是一句小字**。

`heartWord()` 写得再好，也只是一句小字。

### 1.3 手太短

主公现在能做的事：拨一次粮、派一个人、发一支兵、遣一次使。
**每一个都只动一座城。** 没有任何一个动作会改变整张图的形状。

一个诸侯该有的「大局感」，来自他手里有几根能拧动整个天下的杠杆 ——
而现在一根也没有。

### 1.4 还有一条：时间是跳的，不是流的

「散朝」一按，日历跳四十五天，中间发生了什么你不知道。
**跳过去的那四十五天里，天下其实很热闹** —— 只是没人给你看。

---

## 二、总纲：三条腿

| 腿 | 治哪一条 | 一句话 |
|---|---|---|
| **看得见** | 1.1 / 1.2 / 1.4 | 把「等」变成「看」：人一个个上堂，信使一路跑来，屏风上就是天下 |
| **世界在自己走** | 1.1 / 1.4 | 时局、挟天子、共伐 —— 让玩家看见**别人也在做选择** |
| **手要够长** | 1.3 | 国策、驿路、亲征、质任 —— 四根真能拧动整张图的杠杆 |

一条纪律不变：**新东西只拧现成的旋钮**。
下面每一条都要能指出它改的是哪个既有公式。

# 腿一 · 看得见

## 3.1 「传下一位」—— 把散朝改成引见

**这是这份方案里性价比最高的一条，而且几乎不动模拟层。**

现在：案上五张卡片一起摊着，你挨个点，然后按「散朝」跳四十五天。
改成：**堂上一次只站一个人。**

```
court.onStage: string | null      // 正在堂上禀事的那一件

命令  court_next
  · 案上还有人  → onStage = 队首那件。时间不动。
  · 案上没人了  → 退朝：时间往前走到下一件事（就是现在的 cmdAdjourn）
```

界面上，那个人**走上来**：画像从阶下滑入、放大到 120px，说他的话，
你答复，然后 —— 这是关键 —— **他有一个反应，再退下去**。

### 反应由心气决定，这是心气第一次看得见

| 心气 | 你允了 | 你驳了 |
|---|---|---|
| 高 | 深揖：「谢主公。」 | 躬身：「臣愚昧。」 |
| 平 | 抱拳：「诺。」 | 拱手，退下 |
| 低 | 略一颔首 | **一言不发，转身就走**（画像左移出画，不行礼） |
| 到底 | 「……」 | 「……」 |

反应只播 0.6 秒，但**它是整条线的情绪出口**。
`heartWord()` 那句小字可以留着，但玩家真正记住的会是「那次他没行礼」。

模拟层只多一个字段和一个 `memorial_reacted` 事件，表现层做动画。

### 退朝那一下也要有画面

案空了，按「退朝」：堂上的灯一盏盏暗下去，屏风上的天下开始动
（军队走、旗子换、烟起），停在下一件事发生的那一刻。
**那几十天不再是跳过去的，是快放过去的。**

## 3.2 班列 —— 堂上不是列表，是一屋子人

现在的「堂上」是一排卡片。改成**文东武西两列站班**：

- 有职的站前排，闲居的站后排
- **不再上报的人站在最后一排，画得极淡** —— 不写一个字，让玩家自己发现那儿有人
- 按心气决定姿态：心气高的直立，低的躬着，到底的**侧过身去**
- 点一个人 → 大像 + 评语 + 忌 + 现任何职 + **你对他做过的事**（旧账）

> 「主公前年许某取濮阳，至今未发一兵。」
>
> 存每人最近 N 条你的答复，点开就看得见。实现是一个环形数组加几句模板，
> 代价极小 —— 但它是唯一会让玩家记得自己两年前干过什么的东西。

## 3.3 信使 —— 把 `newsDays` 从数字变成画面（外加一个失败模式）

现在 `newsDays()` 只用来给帖子标一句「二十日前」。
改成：**呈报先变成一个骑手，在图上跑，跑到治所才落到你案上。**

```ts
// src/sim/courier_types.ts
export interface Courier {
  id: string;
  /** 已经写好、但还没到你手上的那件事 */
  carry: Memorial;
  fromId: NodeId;
  /** 这一程从哪儿到哪儿。一段一段走，和军队同一套路网 */
  legFrom: NodeId; legTo: NodeId;
  /** 这一程走到哪儿了，千分数 */
  progress: number;
  /** 还剩几程 */
  route: NodeId[];
}
```

- 每日推进，复用 `MARCH_PER_DAY` 那套（骑手比大军快三倍）
- 到治所 → `court.memorials.push(carry)`，发 `courier_arrived`
- **屏风/地图上真的有一个小骑手在跑**，你看着它进城，案上才多一件

### 而且他会被截

这是这条机制真正的价值：

- 他这一程的两头有一头正被围 → 大概率绕道（多花几天）或**被截**
- 路上有敌军 `intent: 'attack'` 走同一段路 → 概率被截
- 被截 → `courier_lost`。**那件事你永远不会知道。**

于是：一座城求援，信使被截，城破了你才从别处听说。
这一条完美接上 v1 里那条设计 ——「案头空了不是太平，是出事了」——
现在它有了第二个原因：**不是人不说话，是话没送到。**

> 情报延迟从一个惩罚，变成了一个能被敌人攻击的系统。

## 3.4 屏风即天下图

**把地图从标签页里搬出来，做成朝堂正后方的一面屏风。**

- 屏风上是天下的缩略投影：旗号、在跑的信使、在走的军队、被围的城冒着烟
- 点屏风 → **推镜头**放大成全屏地图（就是现在的「天下」页），不是切页
- 退朝时快放的那几十天，就演在这面屏风上

这一条同时解决 1.1 和 1.4：你坐在堂上，天下就在你背后动。

## 3.5 露布 —— 战报是叙事，不是数字

打完一仗，案头来一件**不需要答复**的呈报（只有「知道了」）：

> 露布　　濮阳　　　　　　　　　　　十二日前
> 「八月丙申，破敌于濮阳城下。斩首三千余级，获马四百匹。
> 　夏侯惇中流矢，伤右目，已还营将养。」

- 从战斗结果生成，不摆伤害数字（硬规矩一）
- **伤了的人真的从堂上消失若干天** —— 复用现成的 `state.hurt`

# 腿二 · 世界在自己走

## 4.1 时局 —— 全天下同一时刻答同一道题

这是「别人也在做选择」第一次成立的地方。

```ts
// content/situations.json
{
  "id": "taodong", "year": 190, "month": 3,
  "textId": "sit.taodong",
  "options": [
    { "id": "join",  "textId": "sit.taodong.join",
      "effect": { "renown": 12, "grain": -400, "blocAgainst": "dongzhuo" } },
    { "id": "watch", "textId": "sit.taodong.watch", "effect": { "renown": -4 } },
    { "id": "side",  "textId": "sit.taodong.side",
      "effect": { "renown": -25, "attitudeAll": -20, "attitudeFrom": { "dongzhuo": 40 } } }
  ]
}
```

```ts
state.situation: {
  id: string; day: number; dueDay: number;
  answers: Record<FactionId, string>;   // 谁选了什么
} | null
```

### 关键在**分两批揭晓**

1. 时局降临 → 先看到三四家已经表态（「袁绍已出兵」「刘表按兵不动」）
2. **轮到你答** —— 你是看着风向做的决定
3. 你答完，剩下的几家跟着揭晓

这一下就把「一道选择题」变成了「一场博弈」。
界面是一张**天下表态一览**：一家一行，旗、名、他选了什么，
你那一行在中间高亮。

### 时局清单（190 → 200）

| 年 | 时局 | 选项 | 改的是什么 |
|---|---|---|---|
| 190 | 讨董联军 | 出兵 / 观望 / 附董 | 望、粮、结盟阵营、对董的 attitude |
| 191 | 孙坚破洛阳，传国玺现 | 索玺 / 不问 | 望（索了 −）、与孙氏 attitude |
| 192 | 董卓死，长安乱 | 收西凉散兵 / 迎公卿 / 不理 | 兵（+ 但 unrest 高）、望 |
| 193 | 徐州之事 | 声讨 / 缄默 | 望、与加害方 attitude |
| 194 | 兴平大饥 | 开仓 / 闭仓 / 高价出粜 | 望与粮的正面对撞、治下 morale |
| 195 | 天子东归 | 迎 / 遣使贡献 / 不理 | 见 §4.2 |
| 196 | 屯田之法行于天下 | 效之 / 不效 | growNodes 的粮增速、兵源 |
| 动态 | **二强决战**（天下只剩三四家时，最强两家必有一战） | 助甲 / 助乙 / 坐观 | 全局阵营重排 |

AI 怎么答：按 `aggression` / `renown` / 现有 `attitude` 算权重。
**玩家看得见每一家的答案**，于是他第一次能感觉到那十几家是活的。

## 4.2 挟天子 —— 一次性大抉择，换来一根真的杠杆

天子东归那一年，谁离得近谁能迎（`fame ≥ 3` 的城 + 与洛阳的距离）。

### 得到的：下诏

```ts
命令  lord_edict { to: FactionId, kind: 'disband' | 'tribute' | 'yield' | 'denounce' }
```

| 诏 | 内容 | 从了会怎样 |
|---|---|---|
| 罢兵 | 令其解围 / 退兵 | 那支军队真的掉头 |
| 输粮 | 令其贡粮 | 粮车真的往你这儿走 |
| 让地 | 令其让出某城 | 城真的易主（极少有人从） |
| 讨逆 | 点名某家为逆 | 天下对他 attitude 齐降 |

- **一年只下得了两道**。下多了天下不信 —— 诏书的效力按当年已下的道数衰减
- 从与不从：AI 按 `attitude`、你的 `renown`、双方实力判。弱的多半从，强的多半不从
- **不从的那一家，你打他就是「奉诏讨逆」** ——
  打赢 `renown` **涨**，而且跳过 `diplomacy.ts` 里那条「强邻可畏」的忌惮累积。

  这是全局**唯一一个让进攻行为涨望**的开关。它的分量该有多重，就有多重。

### 付出的：天子在你家里是个麻烦

- 每年供养（粮）。行在的排场不是白摆的
- 帐下 `loyalty ≥ 88` 的人心气每季 −1（**他忠的是汉，不是你**）
- **衣带诏**：某一年会来一件呈报 ——

  > 「有人告发：车骑将军与天子密谋，欲图明公。」

  查？杀？还是不理？
  - 杀 → 望 −大，帐下集体寒心（尤其「义」那一路）
  - 不理 → 某一天真的出事（一次针对你的叛乱，从内部起）
  - 查 → 花时间，可能查错人，得罪一整派

**这条抉择没有正确答案 —— 这正是它该有的样子。**

## 4.3 共伐 —— 联盟不是一个数字，是一场约定

当 A 与你有共同的强敌 C，A 会派使者来约：

> 「袁本初遣使：愿与明公共击袁公路，事成之后，汝南归明公。」

- 允 → **双方同日出兵**，图上两支军队一起开拔，C 要分两头守
- 打下来 → 一件新呈报：「盟军请分濮阳」
  - 分给他：`attitude` 大涨，望 +
  - **耍赖**：地留着，`attitude` 崩，望 −，而且他会记很久

**「耍赖」这个选项必须有。** 没有它，联盟就只是一个加成，不是一段关系。

# 腿三 · 手要够长

这三条是 v1 完全没有的东西：**能拧动整张图的杠杆**。

## 5.1 国策 —— 三年才改得了一次，所以每次都是大决定

```ts
court.policy: { id: string; sinceDay: number } | null
命令  lord_policy { id }      // sinceDay + 3*360 之内改不了
```

| 国策 | 利 | 弊 | 改的是 |
|---|---|---|---|
| 屯田 | 粮增速 +25% | 当年兵源 −15% | `growNodes` |
| 求贤令 | 举荐呈报频率翻倍 | 「义」那一路心气 −（唯才是举，不问德行） | `makeRecommend` 的 chance |
| 唯武是尚 | 出兵冷却 −30% | 民心增长 − | `fs.cooldown`、`growNodes` |
| 尊儒重礼 | 望自然增长 +2/年 | 兵源 − | 那条「境内无事」的年结 |
| 弛刑徒 | 立刻得一批兵 | 全境 `unrest` + | 一次性 |
| 与民休息 | `unrest` 衰减加倍、民心涨 | 粮钱产出 −10% | `growNodes` |

**每一条都是既有公式上的一个乘数，一条新规则也没有。**
UI 上是堂中一块牌子，六选一，写清「换到别的要等到某年」。

## 5.2 驿路 —— 把情报延迟变成一个可经营的系统

```ts
court.roads: Record<string, number>    // 边 key → 等级
命令  lord_road { fromId, toId }        // 花粮修驿
```

- 修一段驿：那一段的 `NEWS_DAYS_PER_LINK` 减半，信使被截的概率也减半
- **敌军经过或围城 → 驿断**，恢复原速，且那段路上信使易失
- 地盘越大越是刚需 —— 这是「城多了管不过来」的**第二个具体形态**
  （第一个是人不够，这个是消息跟不上）

## 5.3 亲征 —— 拿内政换战果

```ts
命令  lord_campaign { toId }     // 主公亲自带兵，接现成的 theatre / field
court.away: { since: number; toId: NodeId } | null
```

**好处**：亲征之军士气 +，打赢望 +、帐下心气普涨（「主公与我同在」）。

**代价 —— 这才是关键**：

> 你不在朝堂的这些日子，**案头没人批**。
> 呈报照来、照过期，人心照掉。回来时多半是一堆烂摊子。

这是这条线上最重的取舍，也是「大局操纵感」最直接的一条：
你亲手赢了一场，回头发现三个人不再上报。

## 5.4 质任与联姻 —— 两个纯粹的道德抉择

```
lord_hostage { personId }    家眷留于治所。叛逃权重 ×0.2，心气 −8，且每季再 −1
lord_marry   { factionId }   联姻。attitude +25，三年内他不主动打你；若对方名声差，你的望 −
```

历史上真有质任制，而且正是这么用的。
**它不给你任何好处上的净收益 —— 它只是把「会不会背叛」换成了「他一定恨你」。**
这种交换本身就是玩法。

# 六、还差一口气的两条（收尾）

## 6.1 谥号

结局那一屏，按 `deeds` 算一个谥：

| 谥 | 条件（从 deeds 算） |
|---|---|
| 武 | 开疆多、亲征胜多 |
| 文 | 望高、举荐多、屠戮少 |
| 桓 | 辟土服远 |
| 明 | 用人无失（不再上报者极少） |
| 厉 | 杀戮多、望极低 |
| 灵 | 乱而不损 |
| 炀 | 好大喜功而基业尽失 |

**「谥」是史书对你这一生的一个字。** 比任何分数都狠。

## 6.2 继承人

临终前一件呈报：立谁。

- 长子 / 贤者 / 不立
- 立长而长不肖 → `divided`（袁绍就死在这上头）
- 立贤而废长 → 帐下分裂，但若你望高、心气高，压得住 → `entrusted`
- 不立 → 几乎必然 `divided`

**这一条让「人心」那根柱子一直管到最后一秒。**

# 七、分期

每一期都要能**单独玩**，不许出现「做完三期才好玩」。

### M5a · 临朝（沉浸层最小可玩）**✅ 已完成**

传下一位 + 反应 beat + 班列 + 露布 + 旧账 + 地图方略。

模拟层加的东西比预想的多一点：`court.onStage`、`court.ledger`、
`memorial_staged` / `memorial_reacted` 两个事件、`court_next` 命令，
外加两种新呈报 —— **露布**（不要你批，只要你知道）与
**自请**（空城有人毛遂自荐）。

后面这一条不是锦上添花，是**堵死一个真的死局**：
准了两道辞呈之后辖境就没有守将了，而 `raiseMemorials` 原先挨个城找守将、
一个也找不到 —— 案头从此永远是空的，玩家除了一遍遍「退朝」什么也做不了。
实测就是这么死的。

另外补了**地图方略**（原方案没有）：
点自家的城下令，点别家的城把「攻」和「谈」摆在同一屏上。
理由见 `src/ui/Lord.tsx` 顶上那段 —— 一个诸侯不能只会答复，
他得能自己看着地图说「打这儿」。

踩到的坑记两条，都在代码注释里：
- `pickOf` 用 `^` 算散列，而 **JS 的位异或返回有符号整数**，
  取模落到负半边 → `SKIN[-3]` 是 `undefined` → `fill` 属性整个不见 →
  SVG 默认填黑。**一屋子人里约莫一半是没有脸的黑影。**
- 反应要用他**进来时**那份心气算，不能先扣心气再算 ——
  否则一个平日恭谨的人被驳一次就转身走了，那不是人，是弹簧。

### M5b · 信使与驿路　**✅ 模拟层与界面已完成，图上的骑手未画**

`Courier` 实体、一程一程走、**会被截**、修驿都做了：
- 呈报不再凭空落到案上 —— 从那座城发一骑，走到治所才落案（`sendCourier` / `tickCouriers`）
- 这一程两头有围城（26%）或路上撞见敌军（16%）→ 这一骑没了，
  **那件事你永远不会知道**。界面上不弹任何字：少了一骑本身就是消息
- 修驿（`lord_road`）：那一段走得快六成、被截的几率打四五折；
  **两头有一头被围，驿就断了**
- 朝堂底下有一条「驿传」，报的是路上还有几骑、从哪儿来、大约几天到 ——
  **不报他带的是什么事**。它真正的用处是：少了一骑，你是看得见的

还差的：**图上那个小骑手没画**（`worldmap.ts` 里加一个 `makeRider`）。
这一条纯表现层，不影响机制。

### M5b′ · 地图重画　**✅ 已完成**（原方案没有这一条）

原来的图看不清：地表起伏 ±11 个单位，而河、路、城下的地界都贴在 y≈0 上 ——

### M5c · 时局　**✅ 时局已完成；挟天子与共伐未做**

# 八、怎么验证机制真的活着

老规矩（记忆里 `dead-mechanic-audit`）：**胜率表正常不代表机制跑过。**
`tools/court.ts` 要加这些计数，跑一百局之后打印：

```
信使
  发出            412
  被截             37       ← 0 就是「可截」这条从没生效
  绕道             58
时局
  讨董 · 出兵 / 观望 / 附董     41 / 47 / 12
  大饥 · 开仓 / 闭仓 / 出粜     30 / 55 / 15
  （每一格都得有人选，全押一格 = 那个选项是废的）
天子
  迎              23 局
  下诏            89 道，从者 41
  奉诏讨逆        26 次
  衣带诏发作      19 次
国策
  换过            2.4 次/局
  各条被选        屯田 44 / 求贤 31 / 唯武 18 / …
亲征
  出征            1.7 次/局
  归来时「不再上报」新增   1.3 人   ← 这一行是「代价真的存在」的证据
继承
  立长 / 立贤 / 不立        38 / 44 / 18

  武文桓明厉灵炀            分布
```

**任何一行是 0，那条就是死的，当场回去查。**

同时补测试（`tests/court.test.ts`）：

- 信使被截之后，那件呈报**永远不会**出现在案上
- 亲征期间，呈报照样过期、心气照样掉（代价不是假的）
- 下诏道数超了之后，从者比例**确实**下降
- 时局到期未答，按「最保守那一项」自动结算，且天下表态表上有你那一行
- 国策三年内改不了 —— 这是它「大」的全部来源

# 九、这套东西为什么仍然不破三条硬规矩

1. **不做数值面板** —— 新增的全是话与画面：反应是动作，时局是一张表态表，
   谥是一个字。国策写的是「屯田」不是「+25% 粮」。
2. **资源是对象** —— 信使是图上一个人，粮车是图上一辆车，
   天子是你城里一个要供养的麻烦，人质是堂上少了一个人。
3. **楔子只改权重** —— 时局、国策、诏书，三样全是既有公式上的乘数。
   唯一算得上「新规则」的是信使被截，而它走的是现成的行军与围城判定。

第四条（屏上不超过五个可操作项）**反而更好守了**：
传下一位之后，堂上一次只有一个人、三个答复。
