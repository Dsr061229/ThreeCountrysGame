# 三国 · 一城之治

三国题材的伪 3D 策略游戏。**同一个乱世，三个不同的位置：主公、城池官长、领兵武将。**
而且你能从下往上爬 —— 升迁、叛逃、甚至自立。

完整设计方案见 [docs/设计方案-v2.md](docs/设计方案-v2.md)。

## 玩

网页版（GitHub Pages，推到 `main` 自动部署）：

> **https://dsr061229.github.io/ThreeCountrysGame/**

浏览器里直接开，不用装任何东西。**存档在你自己的浏览器里**（localStorage），
换一台机器就是新的一局。

## 跑起来

```bash
npm install
npm run dev      # → http://localhost:5273
```

## 打包与部署

```bash
npm run build    # → dist/，静态文件，丢哪儿都能跑
npm run preview  # 本地看一眼打包后的样子
```

资源一律用相对路径引（`vite.config.ts` 里的 `base: './'`）——
所以同一份 `dist` 在 Pages 的子路径下、在本地直接打开、在任何静态托管上都跑得起来。

推到 `main` 之后 `.github/workflows/deploy.yml` 会自己跑一遍
`npm run verify`（边界 + 类型 + 测试），**过了才部署**。

## 校验

```bash
npm run verify    # 边界检查 + 类型检查 + 模拟层测试
npm run balance   # 一城之治的推演：把前三年跑一遍，打印曲线
npm run world     # 天下推演：看城池会不会易主、军队会不会满地跑
npm run battle    # 守城战推演：各种摆法的胜率对比
npm run field     # 野战推演：各阵型在不同兵力对比下的胜率
npm run court     # 朝堂推演：跑几十局，看四种结局的分布、机制触发了几次
```

调数值时先跑推演，比在浏览器里点半小时快得多，也比拍脑袋准。

## 当前进度

**M1 · 一城之治** ✅　**M2 · 天下图与部队** ✅　**M3a · 守城战** ✅

一城之治
- 一座城（陈留郡·雍丘），5×5 地块，中心为官署
- 11 种营造，逐级升级，有数量上限（逼多样化，不许堆单一建筑），建好可拆
- 粮 / 钱 / 户口 / 民心 / 守备，全部有对应的视觉呈现
- 季度指标：主公按季索粮索钱，交得上升迁，交不上降职
- 天灾人祸：春旱、大水、蝗、疫疠、溃兵、流民

天下
- 中原十二城、五家势力，各自会发育、会出兵
- 部队在图上真的走，会耗粮，断粮就溃散
- 围城是「耗」不是一天分胜负；打下来的城有离心，新破之城百日内无人再碰
- 主公信得过你，被围时会派援军来
- 两种输法：城破被俘，或连着几季交不上差被撤职

守城战
- **流寇**：开局头几个月就会来第一股，之后一波比一波强，逼你去修兵营和城墙。
  输了只是被抢一笔，不会丢城 —— 这是低风险的实战教学
- 正规军围城若干日之后擂鼓强攻。**打仗时时间停住**
- **战前部署**：把守军分到城头 / 城门 / 预备三处。四个预设按钮一键摆阵，也可细调
  - 城头 → 打崩对方士气，逼他退兵
  - 城门 → 挡住撞木，保住城墙
  - 预备 → 哪里破了往哪里堵，活得久
- **战中两三次决断**：蚁附、撞门、火攻、敌将登城、守军动摇、敌疲、夜幕、粮车
  每个选项都写明在赌什么，赌局标出胜算
- **围而不攻拿不下城**：日常消耗磨不死人，破城只能靠强攻
- 守住一场记功 +25
- **时机是散的，不是打拍子的**：流寇按带抖动的排期来，天灾每日抽而不是季头抽，
  强攻是攻方每日下决心。概率照旧，但没有哪一局的日程表能背下来
  （唯独税期仍落在季交 —— 那一项规律本来就是真实的）

野战
- 城下有敌军时可**出城迎击**。赢了当场解围，输了守军折损、城更难守 —— 是取舍不是更优解
- **看得见的战场**：九列七行的地，坡、林、沼、河滩各有各的作用。
  队伍在格子上真的推进、接触、绞杀，人数掉了小人就少几个
- **布阵靠拖**：把各队拖到阵前两行，脚下是什么地一眼能看见
- **五种阵型**（鱼鳞／锋矢／鹤翼／方圆／偃月），各有得失。
  实测最优阵型随局面变：占优用锋矢、势均用偃月、劣势用方圆
- 战中同样两三次决断，出事时镜头会推到出事的地方

主公 · 临朝
- **默认屏是一间朝堂，不是天下图。** 图退回它该在的位置：一个看局势、下方略的地方
- **一次只见一个人。** 他走上来，说他的话，你答复，**他有一个反应，再退下去** ——
  深揖、抱拳、躬身、颔首，或者一言不发转身就走。
  礼数是**心气**的函数，不是答复的函数：心气高的人被驳了也还躬身，
  心气低的人你允了他也只是颔首。这 0.6 秒是整条线的情绪出口
- **「散朝」变成了「传下一位」**：堂下还有人时它不推时间，人见完了才是「退朝」
- **案上不全是向你伸手的事**：打赢了有人来报**露布**，城空了有人**自请**前往
- 帐下的人呈上来的事 —— 请战、请援、举荐、叙功、求去、来附、自请、劝进、露布 ——
  你批：允 / 留中 / 不许
  - 事情全从天下实况里长出来：请援的城真的正被围，请战的敌城真的挨着他
  - **「留中」不是免费的中立选项**：请援的城会破，请战的人会自己动手
  - 允了不一定办得成 —— 城里没兵就发不出兵。答应一件办不到的事，比驳回还伤人心
  - **不必你拍板的事就不上案头**：某个县今年的口粮该由郡府自己办 ——
    够就发，不够就没有。案头空出来的那一格留给真要你拿主意的事
- **心气是暗的。** 你允了他就涨，驳了就跌，久不理会也跌。
  但你看不到那个数，只看得到他说话的口气（同一件事有恭、平、硬三种说法）。
  **心气到底的人不再上报** —— 所以案头空了不是太平，是出事了
- **令与消息都要走路。** 粮车在图上真的走，到了才入库；
  远处的呈报到案永远标着「多少日前」，你批的时候那座城可能已经破了
- **主公会死。** 寿数是暗的，只给征兆。整局的问题因此变成「我还剩多少年」
- **赢不是你点的按钮，是你的人替你把话说出口。**
  要走到「开国」得凑齐土（名都之分）、名（望）、人（肯替你上劝进表的），
  三根里只有一根是打出来的。没人肯开口，你有全天下的地也称不了
  - 另有一条会死人的路：**不待劝进，自立为帝**（袁术）。赢面小，但赢了最快
- **主公死了，这一局还没完。** 曹操死了有曹丕，孙坚死了有孙策 ——
  死是一次**交接**：日子停在大丧上，先把先主这一代干成的事一条条摆出来，
  再把三样代价写在明处 —— 望要重新挣、心气一齐往下掉、**有人不肯事二主**
  （名字当场列在屏上）。接班的挑的是**心气不是本事**，
  于是「你这一辈子怎么待人」在这一刻第二次结账。
  **真正的输只剩一条：地盘丢光。** 开国 / 托孤 / 身死业分从此不是结局，
  是史书上的一代 —— 终局那一屏列的是历代
- **天下自己往鼎立收**：主亡则乱，弱者归附，十几年下来只剩三五家
- **人物是站着的人，不是框里的头像**：程序生成的立像（零外部美术资源），
  面型、须、冠、袍全从他的评语与擅长里长出来，会拱手会折腰会转身
- **班列**：文东武西站两班，有职的在前，闲居的在后，
  **不再上报的站在最后一排、画得极淡，不写一个字** —— 你得自己发现那儿站着个人
- **呈报是有人骑马送来的**：从那座城发一骑，走到治所才落案。
  路上有围城、有敌军，这一骑就没了 —— **那件事你永远不会知道**。
  修驿能让消息快一半、也不易被截，但两头有一头被围，驿就断了
- **天下图重画**：地压平让河与路露出来，每座城一圈势力色的细环，
  名都描金，城名牌带势力色点 —— 图拉远之后，一排色点就是整张形势图
- **挟天子**：迎了天子，你就能**下诏** —— 罢兵 / 输粮 / 让地 / 讨逆。
  一道诏下去动的是别人的兵；而**抗诏的那一家从此背着一个「逆」字**，
  你打他名正言顺，克城之日望反而涨 —— 全局唯一一处让进攻涨望的开关。
  代价：每年供养、帐下忠汉的人一年年凉下去、以及那一道**衣带诏**
  （杀 / 查 / 不理，三条路都不好走，而且没有正确答案）
- **时局**：讨董、天子东归、兴平大饥 —— **全天下同一时刻答同一道题**，
  而且**分两批揭晓**：先看到三四家已经表态，再轮到你答，你答完剩下的才亮。
  站在同一边的人从此彼此近一层，一齐仇视被指名的那一家 ——
  合纵连横不是一个结盟按钮，是一件事上大家做了同样的选择
- **文官守城，武将领营**：城里的兵守家（乡勇，农忙回家，受开发度的顶约束），
  营里的兵野战（脱产，能练，不受那个顶）—— **出兵不再掏空守军，攻守是两笔账**。
  营每天吃粮，养不起就饿散；营在城外，城被围时它也要一起打
- **募兵**：主公唯一能把粮变成兵的动词。代价是民心，而且**要看农时** ——
  冬为农隙人闲粮足，春耕夏耘抽壮丁伤的是这一年的收成。兵者，农之余
- **营是那位武将自己带起来的**：他每旬在依托的郡里募部曲（出安家费），
  不必主公一勺一勺喂 —— 而且他募的是乡里的丁壮，不是把城墙上站岗的人喊下来
- **上计**：各郡的守官季末把余粮解到治所 —— **这就是太仓的进项**，
  和你当文官时给主公缴的那一笔是同一件事的两头。
  解多少乘着三样你做过的决定：他的文治、他的心气、他的品秩；
  **无人主事的城一粒也解不上来**
- **考课**：帐下的人有功有过、有升有贬（军侯→校尉→中郎将→…／县丞→县令→太守→…）。
  **升要你点头**（名位是最便宜也最有分量的赏赐），**贬不用** ——
  一年年办砸下去位子自己就没了，最低一秩还往下折就是免官，那座城随即空出来
- **请援是几路请缨，不是一个「允」**：城下告急传到堂上，几处同时报上兵数和路程 ——
  快的兵少、多的兵慢、还有一路要向别家借道。挑一路，或者几路都发
- **远征**：「隔着别人的地界兵过不去」那条死规矩拆了。
  拦住一支远征军的是**路、借道、损耗** —— 走几天、经谁的地界、一路散多少人，
  全写在按钮上。借了道那一家对你冷一分，走顺了手他就不肯借了；
  半路那座城换了旗号成了拦路的，军队就地围它 —— 路被堵死了，只好先打这一座
- **堂下无人的时候日子自己走**，一有人上堂就停。要停就按「按住」——
  停的权力在你手上，但默认不该由你出力
- **出师有间歇**：摊子越大，重整旗鼓越慢 —— 和 NPC 同一条闸。**守土不受限**
- **点地图下方略**：点自家的城 → 派人 / 兴修 / 募兵 / 修驿 / 征调 / 从这里出兵；
  点别家的城 → **攻**（每一座自家城、每一座营各是一条路：几天、经谁的境、
  折多少人、到得了多少）与**谈**（遣使、下诏）摆在同一屏上 —— 这才叫「根据战略选」。
  面板可以**收起** —— 图是那一屏真正的主角

## 目录

```
content/       全部游戏内容（JSON，热重载。改一行数值立刻生效）
src/sim/       模拟层 —— 纯 TS，零依赖，确定性。禁止触碰渲染与 DOM
src/view/      表现层 —— Three.js，几何与材质全部代码生成，无外部资源
src/ui/        React 覆盖层，只读快照 + 发命令
src/audio/     Web Audio 现场合成的环境音与音效，无音频文件
tools/         边界检查、平衡推演
tests/         确定性与玩法规则测试
```

## 四条不许违反的规则

1. **模拟层必须是确定的。** 同种子 + 同命令流 = 逐位相同的世界。
   存档回放和联机同步都建在这上面。`npm run check:boundaries` 会拦住违规。
2. **所有状态变更走命令。** 表现层只能 `dispatch`、`getState`、`subscribe`。
3. **推导值绝不存进状态。** 产出、上限、消耗每次都从建筑重新算 ——
   存了就会出现「拆了粮仓但容量还在」这类对不上的 bug。
4. **任何时刻屏幕上不超过五个可操作项。** 不做教程弹窗，用上级的命令当教程。
